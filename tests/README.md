This directory contains tests and required reference material to test the output of the custom rendering implementation. Currently, there are 3 active tests and reference for a fourth

All reference images are rendered at 3441x1440p and the GUI scale is set to 3, causing a single pixel on the Minecraft font to be 3 pixels in the final image.

`styles-no-hud`
This test does a simple basic text rendering task. It renders some different text styles on the bossbar, along with some unicode characters which should be included in the default Minecraft font. The text is being drawn in the bossbar area, where the bar itself is invisible. This test should be recreated with the default resource pack.

It should be drawn with the following text components:

```
[{"text":"Normal"},{"text":" | "},{"text":"Bold","bold":true},{"text":" | ","bold":false},{"text":"Italic","italic":true},{"text":" | "},{"text":"Underlined","underlined":true},{"text":" | "},{"text":"Strikethrough","strikethrough":true},{"text":" | ","strikethrough":false},{"text":"★ ✦ ⚔ ❤ ✧ ◆","color":"aqua"}]
```

`styles-with-hud`
This test is almost identical to the first one, but contains the crosshair and creative hotbar. This test is currently unused, as the rendering engine has no mechanism to draw other elements.

It should be drawn with the following text components:

```
[{"text":"Normal"},{"text":" | "},{"text":"Bold","bold":true},{"text":" | ","bold":false},{"text":"Italic","italic":true},{"text":" | "},{"text":"Underlined","underlined":true},{"text":" | "},{"text":"Strikethrough","strikethrough":true},{"text":" | ","strikethrough":false},{"text":"★ ✦ ⚔ ❤ ✧ ◆","color":"aqua"}]
```

`simple-shader`
This test is again derived from styles, and renders text on the bossbar with the same content. This test introduces a simple, vertex shader which offsets all text down 10 pixels in world space.

It should be drawn with the following text components:

```
[{"text":"Normal"},{"text":" | "},{"text":"Bold","bold":true},{"text":" | ","bold":false},{"text":"Italic","italic":true},{"text":" | "},{"text":"Underlined","underlined":true},{"text":" | "},{"text":"Strikethrough","strikethrough":true},{"text":" | ","strikethrough":false},{"text":"★ ✦ ⚔ ❤ ✧ ◆","color":"aqua"}]
```

`hudkit-prebonk`
This test is the most complex one and uses a resourcepack and text components generated by the Hudkit engine, before its rewrite to the Bonk rendering system. This test introduces custom fonts, negative spacing and more complex vertex shaders.

It should be drawn with the text components from hudkit-prebonk.json
